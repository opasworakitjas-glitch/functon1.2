ลงทะเบียนเข้าเรียน

สื่อการเรียนรู้: ฟังก์ชันกำลังสอง

ห้องทดลองคณิตศาสตร์: ฟังก์ชันกำลังสอง

ยินดีต้อนรับ,

สมการฟังก์ชัน (Equations)

รูปทั่วไป (General Form): y = ax² + bx + c
y = x²
รูปมาตรฐาน (Standard Form): y = a(x-h)² + k
y = (x - 0)² + 0

ปรับตัวแปร (Variables)

คุณสมบัติของกราฟ (Properties)

จุดยอด (Vertex) (0, 0)
จุดตัดแกน Y (0, 0)
จุดตัดแกน X (Roots) x = 0
โดเมน (Domain) จำนวนจริง (R)
เรนจ์ (Range) y ≥ 0

ภารกิจท้าทาย (Interactive Challenge)

คำสั่ง: จงปรับค่า a, b, c ด้านบน เพื่อให้กราฟมี "จุดยอด (Vertex) อยู่ที่พิกัด (2, -3)" และเป็น "กราฟหงาย"

แบบทดสอบความเข้าใจ (Quiz)

1. จุดยอด (Vertex) ของกราฟฟังก์ชัน y = -2x² + 4x - 5 คือจุดใด?

เฉลยและวิธีทำ: ตอบข้อ ข. (1, -3)
จากสมการ a = -2, b = 4, c = -5
หาพิกัด x (h): h = -b / 2a = -4 / (2(-2)) = 1
หาพิกัด y (k): แทน x=1 ลงในสมการ y = -2(1)² + 4(1) - 5 = -3

2. กราฟฟังก์ชัน y = x² - 6x + 9 ตัดแกน X ทั้งหมดกี่จุด?

เฉลยและวิธีทำ: ตอบข้อ ข. 1 จุด
ใช้ค่าดิสคริมิแนนต์ Δ = b² - 4ac
Δ = (-6)² - 4(1)(9) = 36 - 36 = 0
เนื่องจาก Δ = 0 กราฟจึงมีจุดตัดแกน X เพียง 1 จุด

3. โดเมนและเรนจ์ของ y = x² + 2 คืออะไร?

เฉลยและวิธีทำ: ตอบข้อ ก.
โดเมน: x เป็นจำนวนจริงใดๆ ก็ได้ (D = R)
เรนจ์: เนื่องจาก x² ≥ 0 เสมอ ดังนั้น x² + 2 ≥ 2
นั่นคือ ค่า y ต่ำสุดคือ 2 เรนจ์จึงเป็น [2, ∞)
